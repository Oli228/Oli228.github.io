1. 분류(범주)형에서의 분할 방법

  1. CHAID(Chi-Square Automatic Interaction Detection): a predictive model used to forecast scenarios and draw conclusions.
    chi-square value: the difference between a standard, expected scenario and the actual results observed in your data (the maximum chi-square value = the strongest relationship between two variables out of found chi-square values.)

  2. CART(Classification and Regression Trees): non-parametric technique that produces either classification or regression trees, depending on whether the dependent variable is categorical or numeric, respectively. => Gini Impurity
    Used by the CART algorithm, Gini impurity is a measure of how often a randomly chosen element from the set would be incorrectly labeled if it was randomly labeled according to the distribution of labels in the subset. Gini impurity can be computed by summing the probability

  3. C4.5, C5.0: => Entropy
    Entropy is a measure of the amount of uncertainty in the (data) set S. In ID3, entropy is calculated for each remaining attribute. The attribute with the smallest entropy is used to split the set S on this iteration. The higher the entropy, the higher the potential to improve the classification here.

  • Tests in CART are always binary, but C4.5 allows two or more outcomes.
  • CART uses the Gini diversity index to rank tests, whereas C4.5 uses information-based criteria.
  • CART prunes trees using a cost-complexity model whose parameters are estimated by cross-validation; C4.5 uses a single-pass algorithm derived from binomial confidence limits.
  • With respect to missing data, CART looks for surrogate tests that approximate the outcomes when the tested attribute has an unknown value, but C4.5 apportions the case probabilistically among the outcomes. This algorithm typically utilizes Gini impurity to identify the ideal attribute to split on. Gini impurity measures how often a randomly chosen attribute is misclassified. When evaluating using Gini impurity, a lower value is more ideal.

2. 회귀(연속)형에서의 분할 방법

  1. CHAID: ANOVA(Analysis of Variance, 분산분석), F-통계량

    1. ANOVA(Analysis of Variance, 분산분석): 두 개 이상의 그룹 간 평균차이를 비교하는 통계방법
      1. 각 그룹간 평균 차가 우연히 발생했는지 아니면 통계적으로 유의미한지
      2. 집단 내 변동과 집단 간 변동을 비교하여 검증
      3. F-통계량(F-statistics)을 통해 p-value(유의확률)을 계산하여 그룹 간 차이를 평가
    2. F-통계량: 집단 간 변동(between group variance) / 집단 내 변동(within group variance)
      1. p-value가 0.05 미만이면 유의미하다고 판단함
