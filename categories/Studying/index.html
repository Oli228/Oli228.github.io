Chapter 2. 빅데이터 탐색 _ 통계기법의 이해_ 기술통계

1. 개념

1) 정의

  • 기술통계: 데이터를 요약하여 묘사하고 설명하는 통계기법
  • 확률: 통계적 현상의 확실함의 정도
  • 확률변수(X): 사건의 시행의 결과를 하나의 수치로 대응시킬 때의 값
    • 이산확률변수: 확률변수 값의 수가 유한한 변수 *X= {0, 1, 2}
    • 연속확률변수: 확률변수 값의 수가 무한한 변수 *X= 시간, 키, 몸무게 등 셀수 없고 연속적
  • 기댓값(Expected Value): 특정 값을 가질 확률(선형성, 덧셈/곱셈법칙 성립)
    • 이산확률변수: E(X)=∑xf(x)

      주사위 한 번 던져 각 눈의 값 나올 확률 1/6 => 기댓값 E(X)=(1+2+3+4+5+6)/(1/6)=3.5

    • 연속확률변수: E(X)=∫xf(x)dx

      구간 [0, 1]에서 연속인 확률변수 X의 확률밀도함수 f(x)=1 일 때, X의 기댓값 = [1/2x^2 ]= 1/2-0 =1/2

  • 분산(Variance): 확률분포의 산포도를 나타내고 기댓값에서 떨어진 거리의 제곱의 기댓값임
    • 이산확률변수의 분산: E(X)= ∑xf(x)=μ
      • Var(X)=∑(x-μ)^2 f(x)=∑x^2f(x) - μ^2 = E(X^2)-{E(X)}^2
    • 연속확률변수의 분산: E(X)= ∫xf(x)dx=μ
      • Var(X)=E(X^2)-{E(X)}^2
  • 공분산(Covariance): 두 변수의 함께 변하는 정도
  • 사건: 동일 상태로 여러 차례 반복하는 실험이나 관측의 결과로 나타나는 것
  • 표본공간: 통계적 실험에서 모든 발생가능한 실험결과들의 집합

2) 종류

  • 중심화 경향: 데이터의 물리적 상대적 위치 정리
  • 분산도 경향: 데이터의 흩어진 정도
  • 자료의 분포형태: 데이터의 대칭 상태

3) 표본추출

  • 모집단(Population): 관심대상의 전체집합
  • 표본(Sample): 모집단 속에서 일부를 조사한 결과
  • 표본추출 오차(Sampling Bias): 표본의 크기보다는 대표성을 가진 표본 추출이 중요

2. 추출기법

1) 확률표본추출 기법

  • 단순무작위 추출
  • 계통추출: 모집단에서 추출 간격을 설정하여 간격 사이에서 무작위 추출
  • 층화추출: 모집단을 서로 겹치지 않게 특성에 따라 여러 층으로 나눠 분할된 층별로 배정된 표본을 단순 임의 추출법에 따라 추출하는 방법

    예. 모집단 남녀 성비가 3:2면, 표본의 성비도 3:2로 추출

    • 장점: 추정의 정도 높일 수 있음. 각 층별 추정 결과도 얻을 수 있음.
    • 층화변수란? 추출단위가 어느 층에 속하는지 구분이 되는 기준
      • 층화변수가 양적 변수인 경우 층의 최적경계점: n-1개 경계점을 결정하고 추정값의 분산을 최소화하는 경계점 결정
    • 표본배분
      • 비례배분법: 층별 추출단위 수에 비례하여 표본크기를 배분(예. 한 지역 유권자 남녀 3:2, 표본 성비도 3:2로 추출)
      • 네이만배분법: 층별 크기와 층별 변동의 정도를 고려해 변동이 크면 많은 표본 배정
      • 최적배분법: 추정량의 분산을 최소화시키고 주어진 분산 범위 하에 비용 최소화
  • 군집추출: 모집단을 차이가 없는 여러 군집으로 나눠 군집의 단위 일부 또는 전체에 대한 분석

2) 비확률표본추출 기법

  • 간편추출법: 조사원 개인 자의적 판단에 따라 표본 추출 (예. 특정 장소 지나가는 사람 대상 여론조사)
  • 판단추출법: 조사자 개인 나름의 지식과 경험에 의해 표본 추출(예. 교육연구소 연구원이 학생 성적 대표하는 몇 학교 선택)
  • 할당추출법: 조사목적과 밀접 관련있는 조사대상자의 연력잉나 성별 등 변수값에 따라 모집단을 부분집단으로 구분하고, 부분집단별 구성 비율과 표본의 부분집단별 구성 비율이 유사하도록 표본 선정
  • 눈덩이추출법: 접근 어렵고 추출틀 작성이 곤란한 집단은 사람의 소개를 받아 조사

Chapter 2. 빅데이터 탐색 _데이터 탐색_ 데이터탐색의 기초

  1. 데이터 탐색의 개요

    1. 탐색적 데이터 분석(Exploratory Data Analysis, EDA)
      가. 이상치 검출 방법
      - 개별 데이터 관찰
      - 통계값 활용
      - 데이터 중심: 평균(mean), 중앙값(median), 최빈값(mode)
      - 데이터 분산도: 범위(range), 분산(variance)
      - IQR(Inter Quartile Range): 전체 데이터를 오름차순 정렬하고 4등분
      - 최대값: 전체 75% 지점 : 3사분위 수 + 1.5IQR
      - 최소값: 25% 지점: 1사분위수 - 1.5IQR
      - 최대값보다 크고, 최소값보다 작으면 이상치로 간주(터키펜스)
      - 정규분포: 평균을 중ㅅ미으로 좌우대칭인 종모양을 이루는 분포로 변경하여 어느 정도의 값이 이상치인지 직접 판단
      - 시각화 활용
      - 머신러닝 기법: K-means를 통해 이상치 확인

  2. 상관관계분석

    1. 변수 간의 상관성 분석: 단순상관분석, 다중상관분석(편상관관계분석: 다중상관분석에서 다른 변수와의 관계를 고정하고 두 변수의 관계강도를 측정)
    2. 상관분석의 기본가정:
      가. 선형성: x, y 관계가 직선인지 알아보는 것으로 산점도(분포 나타내는 그래프)로 확인
      나. 등분산성(동변량성, homoscedasticity): x값과 관계없이 y의 흩어진 정도가 같은 것(<-> 이분산성(heteroscedasticity)
      다. 정규분포성: 두 변인의 측정지 분포가 모집단에서 모두 정규분포를 이루는 것
      라. 무선독립표본: 모집단에서 표본을 뽑을 때 표본 대상이 확률적으로 선정된다는 것
    3. 상관분석 방법
      가. 피어슨 상관계수: 두 변수 x, y간 선형 상관관계를 계량화한 수치(-1 ~ +1)
      나. 스피어만 상관계수: 두 변수 x,y간 연관관계가 있는지 없는지 밝혀주며 자료에 이상점이 있거나 표본크기가 작을 때 유용함. (특히 데이터가 서열자료일 때)

  3. 기초통계량의 추출 및 이해

    1. 중심화 경향 기초통계량

      • 산술평균(Arithmetic Mean): 모든 자료 합하여 전체 자료 수로 나눔
        • 모평균(Population Mean): 모집단 전체 자료의 산술 평균
        • 표본평균(Sample Mean): 모집단의 부분집합인 추출된 표본 전체의 산술평균
      • 기하평균(Geometric mean): n개의 자료에 대해 관측치를 곱하고 n제곱근
      • 조화평균(Harmonic mean): 각 요소의 역수의 산술평균을 구한 후 다시 역수를 취함
      • 자료가 서로 다를 경우 조화평균 < 기하평균 < 산술평균의 부등신 관계를 가짐
      • 중앙값(Median): 자료 크기 순으로 나열할 때 가운데 값
      • 최빈값(Mode): 가장 노출 빈도가 높은 자료
      • 분위수(Quantile): 자료의 위치를 표현하는 수치
        • 자료를 4등분 하면 사분위수(quartile), 5등분하면 오분위수(quintile) …..

    2. 산포도(분산도, degree dispersion): 중심 경향도 수치에서 자료가 얼마나 떨어졌는지 측정하는 척도

      • 분산(variance): 평균을 중심으로 밀집되거나 퍼짐 정도를 나타내는 척도
      • 표준편차(standard deviation): 분산의 제곱근
      • 범위(range): 데이터 간 최댓값과 최솟값의 차이
      • 평균절대편차(평균편차, 절대편차, Mean Absolute Deviation): 각 자료값과 표본평균과의 편차의 절대값에 대한 산술평균 => 절댓값을 사용하므로 수리적으로 다루기 부적절해 분산을 더 선호
      • 사분위범위(Inter Quartile Range): 최댓값(Q3+1.5xIQR) 초과하고 최솟값(Q1-1.5xIQR) 미만이면 이상치로 간주 IQR = Q3-Q1
      • 변동계수(Coefficient of Variance, CV): 평균을 중심으로 한 상대적인 산포의 척도로
        표준편차 / 평균으로 계산하고 값이 클수록 변동이 더 크다고 해석

    3. 자료의 분포형태

      • 왜도(Skewness): 왼쪽으로 치우치면 양수, 오른쪽으로 치우치면 음수
        • 피어슨의 비대칭계수는 3을 곱해 좀 더 비대칭을 강조
      • 첨도(Kurtosis): 분포의 뾰족한 정도를 나타내는 통계적 척도
        1️⃣ 첨도는 음수가 될 수 없음. 2️⃣ 단위가 없음 3️⃣ 초과첨도는 첨도에서 3을 뺀 값으로 일반 첨도를 정규분포에 맞춰 조정한 개념이므로 초과 첨도는 0이 될 수 있음

    4. 시각적 데이터 탐색
      - 도수분포표
      - 히스토그램: 가로축을 반드시 수량을 표시하는 자료분포를 나타내는 그래프
      - 막대그래프: 각 자료값에 대한 도수를 그림으로 표현(가로축이 반드시 수량일 필요 없음)
      - 파이차트
      - 산점도: 직교 좌표계를 이용해 두 변수 간 관계를 나타냄
      - 줄기-잎 그림: (예. 10자리는 줄기, 1자리는 잎 등으로 표현)
      - 상자수염 그림(Box Plot): 최솟값, Q1, Q2, Q3, 최댓값을 그리는 것. IQR = Q3- Q1

Chapter 2. 빅데이터 탐색 _분석 변수 처리_

  1. 변수선택방법: 전진선택법, 후진선택법, 단계적 선택법

    1. 전진선택법: 영 모형에서 시작, 종속변수와 상관계수 높은 독립변수를 분석모형에 포함

      • 부분 F검정을 통해 유의성 검증 시행하여, 유의한 경우 가장 큰 F통계량 가진 모형 선택
        ** 한 번 추가된 변수는 제거하지 않음

    2. 후진선택법: 전체 모형에서 시작, 종속변수와 상관계수가 가장 낮은 독립변수를 모형에서 제외

      • 부분 F검정을 통해 유의성 검증 시행하여, 유의하지 않은 경우 변수 제거, 유의하면 중단
        ** 한 번 제거된 변수는 추가하지 않음

    3. 단계적선택법: 전진선택법과 후진선택법의 보완방법

      • 전진선택법으로 가장 유의한 변수를 모형에 포함 후 나머지 변수들에 대해 후진선택법으로 유의하지 않은 변수들을 제거함
      • 제거된 변수는 다시 모형에 포함하지 않으며 유의한 설명변수가 존재하지 않을 때까지 과정 반복

  2. 차원축소 **차원이란? 분석하는 데이터의 종류의 수

    1. 차원축소의 필요성
      가. 동일 품질을 나타낼 수 있으면 효율성 측면에서 데이터 종류의 수를 줄여야 함
      나. 과적합 방지: 과적합은 분석모형의 정확도(신뢰도) 저하
      다. 해석력 확보: 차원이 간단할수록 이해가 용이하고 해석이 쉽고 명확함
      라. 차원의 저주: 차원이 증가하면 학습데이터의 수가 차원의 수보다 적어져 성능이 저하됨.

    2. 차원축소의 방법
      가. 요인분석(Factor Analysis): 다수의 변수들 간의 관계를 분석하여 공통차원을 축약하는 통계분석
      - 목적:
      - (변수축소) 다수의 변수들의 정보손실 억제하면서 소수의 요인으로 축약
      - (변수제거) 요인에 대한 중요도 파악
      - (변수특성 파악) 관련변수들이 묶임으로써 요인 간 상호독립성 파악 용이
      - (타당성평가) 묶이지 않은 변수의 독립성 여부 판단
      - (파생변수) 요인점수를 이용한 새로운 변수를 생성
      - 특징: 독립변수, 종속분수 개념 없음
      - 종류: 주성분 분석, 공통요인분석, 특이값 분해 행렬, 음수미포함 행렬분해 등
      나. 주성분분석(Principal Component Analysis): 분포된 데이터들의 특성을 설명할 수 있는 하나 또는 복수 개의 특징을 찾는 것 ( 데이터 하나하나에 대한 성분분석이 아니라, 여러 데이터들이 모여 하나의 분포를 이룰 때 이 분포의 주성분을 분석하는 방법)
      - 서로 연관성 있는 고차원공간의 데이터를 선형연관성 없는 저차원(주성분)으로 변환
      - 기존의 기본변수들을 새로운 변수의 세트로 변환하여 차원을 줄이되 기존변수들의 분포특성을 최대한 보존하여 이를 통한 분석결과의 신뢰성을 확보
      - 특징
      - 차원 축소에 폭 넓게 쓰임(사전적 분포 가정의 요구 없음)
      - 가장 큰 분산의 방향들이 주요 중심 관심으로 가정
      - 선형결합으로만 고려
      - 차원 축소는 본래 변수가 서로 상관이 되어야 가능
      다. 특이값 분해(Singular Value Decomposition, SVD): 데이터 공간을 나타내는 m x n 크기의 행렬 M에 대해 다음과 같이 분해 가능
      M = U∑V^t
      - M: mxn 크기의 직교행렬(Orthogonal Matrix: 행렬의 열벡터가 독립인 행렬)
      - U: mxm 크기의 직교행렬
      - ∑: mxn 크기의 직교행렬
      - V^t : nxn크기의 직교행렬
      => 행렬 M을 여러 개의 행렬 M과 동일한 크기를 갖는 행렬로 분해할 수 있으며 각 행렬의 원소값의 크기는 대각행렬의 대각성분의 크기에 의해 결정(대각행렬: 대각성분을 제외한 나머지 행렬의 원소값이 0)
      LSA(Latest Semantic Analysis): 특이값 분해를 활용하여 문서-단어 행렬을 차원 축소하고 잠재의미(의미적 유사성)를 추출하는 기법
      라. 음수 미포함 행렬분해(NMF): 음수를 포함하지 않는 행렬을 음수를 포함하지 않는 두 행렬의 곱으로 분해하는 알고리즘

  3. 파생변수의 생성

    1. 개념: 기존 변수를 조합하여 새로운 변수를 만드는 것 (주관적 변수 개념)
      • 전 데이터 구간에 대표성을 가지는 변수를 파생변수로 해야 함 *
        ** 요약변수: 수집된 정보를 분석에 맞게 종합(aggregate)한 변수 => 데이터마트의 가장 기본적인 변수 (단순 종합 개념)
    2. 생성방법
      가. 한 값으로부터 특징 추출
      나. 한 레코드 내의 값들을 결합
      다. 다른 테이블의 부가정보 결합
      라. 다수의 필드 내 시간 종속적 데이터 선택
      마. 레코드 또는 중요 필드 요약
    3. 교호작용을 포함한 파생변수 생성: 두 개 이상의 독립변수가 함께 작용해 종속변수에 영향 미치는 경우

  4. 변수 변환

    1. 개념: 데이터를 분석하기 좋은 형태로 바꾸는 작업

    2. 방법
      1️⃣ 범주형 변환: 연속적 데이터를 범주형 데이터로 범주 나누어 상대비교하는 방법 효과적일 수 있음(예. 소득이라는 연속적 데이터 -> 소득구간 범위로 구분)
      2️⃣ 정규화: 수치로 된 값들을 여러 개 사용할 때 각 수치의 범위가 다르면 이를 같은 범위로 변환(예. 과목 A 시험은 10점 만점, B는 50점 만점이면 개인별 받은 점수에서 각 만점점수를 나눠 정규화함)
      - 최소-최대 정규화: 모든 특징을 최소값 0, 최대값 1로, 그리고 다른 값들은 0~1 값으로 변환 (단점: 이상치 영향 많이 받음)
      - z-score 정규화: Z = (X-평균)/표준편차 (이상치는 잘 처리하지만, 정확히 동일척도로 정규화된 데이터를 생성하지 않음)
      3️⃣ 로그 변환: 로그를 취하면 그 분포가 정규 분포에 가깝게 분포하는 경우가 있음
      - 로그변환분포를 사용하는 전형적 데이터: 국가별 수출액, 사람의 통증 정도 수치화
      - 데이터 분포의 형태가 좌측으로 치우친 경우
      4️⃣ 역수 변환: 역수를 취하면 오히려 선형적인 특성을 갖게 되는 경우가 있음
      - 데이터 분포의 형태가 좌측으로 치우친 경우
      5️⃣ 지수 변환: 지수를 취하면 오히려 선형적인 특성을 갖게 되는 경우가 있음
      - 데이터 분포의 형태가 우측으로 치우친 경우
      6️⃣ 제곱근 변환: 제곱근을 취하면 오히려 선형적인 특성을 갖게 되는 경우가 있음
      - 데이터 분포의 형태가 좌측으로 약간 치우친 경우
      7️⃣ Box-Cox: 양수데이터가 비대칭 분포를 가질 때 사용, 계수가 0이 아니면 멱변환*, 0이면 로그변환
      * 멱변환: 데이터를 어떤 지수의 거듭제곱으로 변환하는 것

    3. 분포형태별 정규분포로의 변환 (분포형태 시각화 하는 방법: 샤피로 테스트, Q-Q 플롯)
      1️⃣ 우로 치우침(Negative Skew, Left-Skewed): X^3
      2️⃣ 우로 약간 치우침(Negative Skew, Left-Skewed): X^2
      3️⃣ 좌로 약간 치우침(Positive Skew, Right-Skewed): Square(X)
      4️⃣ 좌로 치우침(Positive Skew, Right-Skewed): ln(X)
      5️⃣ 극단적 좌로 치우침(Positive Skew, Right-Skewed): 1/X

  5. 불균형 데이터 처리: 데이터 양의 차이가 큰 경우 클래스 불균형이라고 함

    1. 문제점: 특정 범주에서 정확도가 높아지면 모형의 성능 판별 어려움
      즉, 정확도가 높아도 데이터 개수가 적은 클래스의 재현율(recall-rate)는 급격히 작아짐
    2. 불균형 데이터의 처리 방법
      1️⃣ 가중치 균형법: 데이터에서 손실 계산 시, 특정 클래스의 데이터에 더 큰 손실값을 갖게 하는 방법
      2️⃣ 언더샘플링과 오버샘플링
      - 언더샘플링: 대표클래스의 일부 대표만 선택, 소수클래스는 최대한 많은 데이터 선택
      - 오버샘플링: 소수클래스의 복사본을 만들어 대표클래스 수 만큼 만드는 것

  6. 인코딩: 범주형 데이터를 수치형 데이터로 변환하여 머신러닝 모델에 적용 가능하게 하는 기법

    1. 레이블 인코딩: 각 범주에서 순차적인 정수 레이블을 할당하여 데이터를 변환 (옷 사이즈 )
    2. 원-핫 인코딩: 각 범주에 대해 해당하는 인덱스만 1이고 나머지는 0인 이진 벡터로 변환함
    3. 타깃 인코딩: 주로 분류에서 사용되며 각 범주에 대한 종속변수(타깃)의 평균값을 인코딩으로 사용
      • 목적: 범주형 변수의 각 범주가 종속변수와 어떤 관계를 갖는지 수치화하고 모델이 학습함
      • 수행단계
        • 범주형 변수의 각 범주에 대해 종속 변수의 평균값을 계산
        • 계산된 평균 값을 해당 범주에 대한 인코딩 값으로 대체
      • 주의사항: 과적합 가능성이 있고, 훈련 데이터에만 적용되어야 함. 범주 수가 적거나 데이터가 적으면 적절하지 않을 수 있음

Chapter 2. 빅데이터 탐색 _데이터 전처리_ 데이터정제

  1. 데이터의 정제
    가. 개념: 수집된 데이터를 대상으로 분석에 필요한 데이터를 추출하고 통합하는 과정
    나. 필요성: 정제를 거치지 않으면 일관성이 부족해 분석도구 적용 어려우며 분석이 왜곡되거나 신뢰도 저하
    다. 정제의 과정: 수집-변환-교정-통합
  2. 데이터 결측값
    가. 처리
    - 임의로 제거 시: 분석에 필요한 유의수준 데이터 수집에 실패할 가능성 발생
    - 임의로 대체 시: 데이터 편향 발생하여 분석 결과의 신뢰성 저하 가능성 발생
    나. 종류
    - 완전 무작위 결측: 결측 데이터가 관측된/관측되지 않은 모든 다른 변수와 아무 연관 없음
    - 무작위 결측: 결측 데이터가 관측된 다른 변수와 연관은 있으나 그 자체가 비관측값들과는 연관없음
    - 비 무작위 결측: 결측 데이터가 완전 무작위 결측이나 무작위 결측이 아닌 결측데이터로 정의하는 즉, 결측변수값이 결측여부와 관련 있는 경우
    다. 결측값 유형의 분석 및 대치
    - 단순 대치법
    - 완전 분석: 불완전 자료는 완전무시하고 분석(분석은 용이, 단 추론의 타당성에 문제 발생)
    - 평균 대치법: 데이터의 평균으로 결측치를 대치(효율성 향상, 단 통계량의 표준오차 과소추정)
    - 회귀 대치법: 회귀분석에 의한 예측치로 결측치 대치(데이터의 변동성 반영, 단 회귀모델의 정확도에 따라 값의 정확도 변화하고 독립변수와 종속변수 간 관계가 약한 경우 예측값의 신뢰성이 떨어짐)
    - 단순확률 대치법: 확률추출에 의해 전체 데이터에서 무작위 추출(평균대치법의 과소추정 보완)
    - 최근접 대치법: 전체표본을 몇 개의 대체군으로 분류하여 각 층에서의 응답자료를 순서대로 정리한 후 결측값 바로 이전의 응답을 결측치로 대치
    - 다중 대치법: 단수 대치법을 N번 시행하여 효율성 및 일치성 문제 보완
    - 1단계 대치단계: 복수의 대치에 의한 결측을 대치한 데이터를 생성
    - 2단계 분석단계; 복수 개의 데이터셋에 대한 분석
    - 3단계 결합단계: 복수 개의 분석결과에 대한 통계적 결합
  3. 데이터 이상값 처리
    가. 이상값: 정상범주에서 벗어난 값
    나. 이상치 탐지
    1️⃣ 시각화를 통한 방법(비모수적, 단변량(2변량)의 경우)
    - 상자 수염 그림(Box Plot): 데이터 분포를 시각화하여 여러 집단을 한 공간에 쉽게 나타냄. 데이터의 최솟값, 최댓값, 중앙값, 1사분위수(Q1), 3사분위수(Q3)등을 고려해야 함
    - 1사분위 수: 데이터 정렬했을 때 25%에 위치한 수
    - 3사분위 수: 75%에 위치한 수
    - IQR = 3사분위 수 - 1사분위 수: 데이터의 중간 50%가 퍼져있는 범위를 나타내는 산포(흩어짐)의 척도
    - 최댓값: 3사분위수 + (1.5 IQR), 최솟값: 1사분위 수 - (1.5 IQR)
    - 줄기-잎 그림: 주로 작은 데이터 셋에 적합하며 숫자의 일부인 줄기와 그 줄기에 해당하는 값들의 리스트인 잎으로 분리하여 나타냄
    - 산점도 그림(Scatter Plot): 두 변수로 이루어진 데이터를 2차원 평면 상에 점으로 시각화.
    2️⃣ z-score를 이용한 이상치 탐지 방법
    * z-score: 데이터 포인트가 평균으로부터 얼마나 떨어져 있는지를 표준편차의 단위로 나타내는 통계적 지표
    - 데이터 정규화하여 표준정규분포(평균0, 표준편차1)로 변환함
    - 정규화된 데이터 포인트의 z-score를 계산
    - z-score의 절대값이 일정한 임계값보다 큰 데이터는 이상치로 간주(예.전체의 68.27%)
    3️⃣ 밀도기반 클러스터링 방법(DBSCAN)
    - 비모수적 다변량일 때 군집간 밀도를 이용하여 특정 거리 내 데이터 수가 지정 개수 이상이면 군집으로 정의 => 정의된 군집에서 먼거리에 있는 데이터는 이상치로 간주
    4️⃣ 고립 의사나무 방법(Isolation Forest)
    - 데이터가 다른 데이터들과 얼마나 분리되어 있는지를 측정하여 이상치를 탐지

24. 100, 200, 300의 값을 z-score로 변환할 때, 표준편차 100으로 정하고 변환함수 f(x)= ax+b를 사용하였을 때 a+b의 값은? (중요한데 잘 모르겠음)

  1. 평균: 100+200+300 / 3 = 200
  2. 표준편차 = 100
  3. z-score = x-평균 / 표준편차
  4. 계수 = 1/ 100
  5. 상수 b = - 평균/표준편차 = 200/100 =-2
  6. a+b = 0.01-2

3) 이상치에 판별로 활용된다.
4) Q1은 하위 25% 지점의 값이다.
